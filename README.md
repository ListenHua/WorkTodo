# WorkTodo

WorkTodo是一款面向 macOS 和 Windows 的本地项目与待办桌面应用。无需账号，项目、待办、配置、文字与图片草稿保存在工作目录的 JSON 和资源文件中；SQLite 作为本机可重建查询缓存。旧安装可复制升级，保留原数据。

当前版本：**0.0.1**。

## 主要功能

- **项目空间**：创建与编辑项目、归档与恢复，标记常用项目至侧栏快捷访问，支持右键新建、自定义排序、名称与创建时间排序，以及项目标签复用和自定义颜色。
- **待办管理**：快速录入、编辑、状态切换、截止时间、组合筛选与排序，支持删除、撤销和回收站恢复。
- **本地文件**：项目与本地文件夹联动，支持待办附件、搜索、类型筛选、图片预览、右键打开与定位、批量删除及缺失文件记录清理。
- **项目链接**：管理常用网站，使用官方图标、名称首字或提取的网站图标，支持拖拽调整顺序，点击后在系统默认浏览器中打开。
- **快捷采集**：通过全局快捷键或自定义鼠标、键盘按键长按采集文本与图片，默认使用鼠标中键。
- **桌面提醒**：截止时间提醒、提醒中心、托盘常驻与后台通知。
- **全局快捷键**：快捷添加待办（macOS：Control + Command + D；Windows：Ctrl + Alt + D）、显示/隐藏窗口（macOS：Control + Command + E；Windows：Ctrl + Alt + E），可在“设置 → 桌面与提醒”修改、停用或恢复默认，冲突时提示并保留原绑定。
- **概览仪表盘**：自适应铺满窗口的统计卡片与滚动数字，展示项目待办柱状图、今天及前后三天共七天的新增与完成趋势，集中查看今日待办、逾期任务及项目进度。
- **目录存储**：直接选择或更换本地文件夹，读取该目录自身的项目、待办与文件；普通文件夹按需初始化，原有文件保留。
- **个性化设置**：中文界面、明暗主题切换与跟随系统，自定义采集和提醒偏好。

## 项目目录联动

新安装不预设项目存储位置，也不自动创建项目数据目录。在设置中“选择存储目录”后，直接读取已有 WorkTodo 数据；空文件夹或普通非空文件夹只初始化缺少的 `config.json`、`todo.json`、`Files/` 等必要内容，不移动已有文件。若有不属于 WorkTodo 的同名配置文件，则提示具体冲突位置并保留原件。创建项目会建立同名文件夹，配置与待办分别保存在 `config.json`、`todo.json`，附件统一放入 `Files/`：

```text
/project/
├── config.json
├── todo.json
├── Files/
├── 农田管理/
│   ├── config.json
│   ├── todo.json
│   ├── Files/
│   │   ├── 现场图片.png
│   │   └── 项目文档.pdf
│   └── .assets/link-icons/
├── _回收站/
└── .workspace/drafts/
```

主题、采集、提醒等偏好随工作目录保存；目录的绝对位置、本机系统授权和通知投递记录分别保存在本机。“更换存储目录”只切换当前管理的位置，不复制项目、待办、附件、偏好或草稿。A、B 目录可以来回打开，各自保持独立；原目录已移动、删除或不可访问时，仍可选择其他目录。所选目录成功打开后才更新当前路径，并刷新界面和提醒。切换前保存采集草稿，无法写回时保存在本机恢复稿中，不带入新目录。

更换目录不再自动整理或复制旧版数据库中的数据。普通文件和未登记的子文件夹显示在项目空间的“目录文件”中，点击使用系统默认应用打开；普通子文件夹不会自动创建为项目。已有完整项目可用“导入项目副本”保留其信息。读取只检查必要的数据结构，不要求目录设备身份、历史文件哈希或快照版本一致，合法的外部 JSON 修改会刷新到界面。JSON 损坏时保留原文件并阻止写入，有缓存时可只读查看；本机恢复稿可单独导出或归档。

已有同名普通文件夹可在确认后合并，其原内容移入 `Files/`；已有完整项目应使用“导入项目副本”，重建 ID 并保留来源。源文件保留，跨项目移动任务时复制附件，删除文件时移入 `_回收站`。外部文件变化经用户确认后更新校验摘要。

## 开始开发

技术栈：Tauri 2、Vue 3、TypeScript、Rust、SQLite、Pinia、Naive UI 和 MingCute。默认采用黑白主题，浅色模式主题色为 `#000000`，深色模式采用反向黑白配色，使用 Magic UI Animated Theme Toggler 的 Vue 适配版切换主题。

需要 Node.js 22、pnpm 9.15、Rust stable 和对应平台的原生构建工具。macOS 需要 Xcode Command Line Tools；Windows 需要 MSVC Build Tools（C++ 桌面开发与 Windows SDK）和 WebView2。

```bash
pnpm install
pnpm desktop:dev
```

仅预览界面时运行 `pnpm dev`。浏览器预览使用临时数据，真实目录数据、文件操作和缓存重建通过桌面应用使用。

## 常用命令

| 命令                         | 用途                                         |
| ---------------------------- | -------------------------------------------- |
| `pnpm check`                 | 前端类型检查与生产构建                       |
| `pnpm rust:check`            | Rust 编译检查                                |
| `pnpm rust:lint`             | Rust 静态检查                                |
| `pnpm rust:test`             | 执行随源码保留的 Rust 内嵌测试               |
| `pnpm build:mac`             | 构建当前架构的 Mac APP 和 DMG                |
| `pnpm build:windows`         | 构建 Windows NSIS 安装器                     |
| `pnpm version:check`         | 核对前端、Tauri、Cargo、锁文件与更新日志版本 |
| `pnpm changelog:generate`    | 从 `changelog.json` 生成 `CHANGELOG.md`      |
| `pnpm version:prepare 0.0.2` | 将未发布变更冻结为下一版本                   |
| `pnpm release:check`         | 执行格式、版本、前端构建与 Rust 检查         |

`docs/` 和独立测试用例仅在本地保留，不随仓库分发。`pnpm test`、`pnpm test:watch` 和 `pnpm test:e2e` 需要本地测试文件，CI 和发布检查不调用这些命令。

macOS 安装：打开 DMG，将左侧“WorkTodo”应用拖入右侧“应用程序”文件夹，复制完成后从“应用程序”启动。安装盘包含固定的左右布局、箭头和中文说明。构建 DMG 需要可用的 Finder 会话；若系统询问自动化权限，请允许构建终端控制 Finder，以便写入安装界面布局。背景资源已随仓库保存，调整背景后可在 macOS 运行 `swift scripts/generate-dmg-background.swift` 重新生成。

设置中的“关于”可查看当前版本、离线更新日志并复制版本信息。GitHub Release 提供 macOS Apple Silicon DMG 和 Windows x64 安装器。

私钥、签名证书和签名产物不纳入版本管理。构建和签名校验脚本随源码保留，正式签名材料在构建时从本机或 CI 环境提供。

更新日期：2026-11-17。
