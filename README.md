# WorkTodo

WorkTodo 是面向 macOS 和 Windows 的本地项目与待办应用，无需账号。项目、待办、配置和附件保存在所选工作目录，SQLite 仅作为可重建的本机查询缓存。

当前版本：**0.0.4**。完整更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- **项目空间**：新建、编辑、归档、快捷访问、彩色标签与链接管理；项目卡片采用瀑布流布局，排序模式支持直接拖拽和实时预览。
- **文件夹创建项目**：点击项目空间新增按钮左侧的文件夹图标，搜索并选择已有文件夹创建项目，普通目录不会自动变成项目。
- **待办管理**：统一普通新建与快捷添加表单，支持项目归属、描述、计划日期、优先级、状态、截止时间、提醒及附件；按优先级排序，提供卡片瀑布流与概览列表。
- **回收站**：按项目与删除时间筛选，支持批量恢复、批量彻底删除和清空，危险操作确认范围并反馈失败项目。
- **概览**：查看全部未完成待办、今日待办、项目进度与待办分布，以及今天前后三天共七天的趋势。
- **本地文件与链接**：导入附件、搜索和筛选文件、预览图片、打开或定位文件、管理网站链接并拖拽排序。
- **桌面提醒与托盘**：系统通知、提醒中心、后台常驻，托盘提供添加或查看待办与项目、显示或隐藏窗口、设置和退出。
- **快捷采集**：通过快捷键或自定义鼠标、键盘按键长按采集文字与图片，支持草稿保存。
- **个性化**：黑白主题、明暗模式与跟随系统，统一插画空状态和同行快捷操作。

默认快捷键可在设置中修改、停用或恢复默认，绑定冲突时会提示：

| 操作           | macOS                 | Windows        |
| -------------- | --------------------- | -------------- |
| 快捷添加待办   | Control + Command + D | Ctrl + Alt + D |
| 显示或隐藏窗口 | Control + Command + E | Ctrl + Alt + E |

## 存储与删除

首次使用时选择存储目录。应用直接打开所选目录的数据，普通文件夹只初始化缺少的必要内容，不移动原有文件；遇到不兼容的同名配置文件时会提示具体位置并保留原件。

```text
工作目录/
├── config.json
├── todo.json
├── Files/
├── 项目名称/
│   ├── config.json
│   ├── todo.json
│   ├── Files/
│   └── .assets/link-icons/
├── _回收站/
└── .workspace/drafts/
```

“更换存储目录”只切换当前管理的位置，不复制或迁移原目录的数据。不同目录分别保留自己的项目、待办、偏好和草稿；原目录不可访问时仍可选择其他目录。合法的外部配置修改会刷新到界面；损坏的配置会保留原件并阻止覆盖写入。

删除项目默认只删除记录并保留文件夹，即使文件夹已经移动或删除，也可清理项目记录。只有主动勾选“是否删除文件夹下的数据与文件”时才处理对应目录内容。待办删除后可在回收站恢复。回收站支持批量恢复、彻底删除与清空；彻底删除会清理待办记录、提醒和附件关联，保留实际附件文件。

## 开发与校验

技术栈：Tauri 2、Vue 3、TypeScript、Rust、SQLite、Pinia、Naive UI 和 MingCute。

需要 Node.js 22、pnpm 9.15、Rust stable。macOS 需要 Xcode Command Line Tools；Windows 需要 MSVC Build Tools、Windows SDK 与 WebView2。

```bash
pnpm install --frozen-lockfile
pnpm desktop:dev
```

仅预览界面时运行 `pnpm dev`，浏览器使用本地预览数据，不会读写真实工作目录。

| 命令                         | 用途                               |
| ---------------------------- | ---------------------------------- |
| `pnpm check`                 | 类型检查、版本核对与前端构建       |
| `pnpm format:check`          | 源码格式检查                       |
| `pnpm rust:fmt -- --check`   | Rust 格式检查                      |
| `pnpm rust:lint`             | Rust 静态检查                      |
| `pnpm rust:check`            | 原生服务编译检查                   |
| `pnpm icons:generate`        | 生成应用图标、应用内标识与托盘图标 |
| `pnpm build:mac`             | 构建当前架构的 macOS APP 和 DMG    |
| `pnpm build:windows`         | 构建 Windows NSIS 安装器           |
| `pnpm version:prepare 0.0.4` | 将未发布更新冻结为下一版本         |
| `pnpm changelog:generate`    | 从 changelog.json 生成更新日志     |
| `pnpm release:check`         | 运行发布前的格式、版本与编译检查   |

## 安装与发布

GitHub Release 仅提供以下四类附件，名称统一以 `WorkTodo` 开头：

- macOS Apple Silicon：`.dmg` 安装镜像与 `.app.zip` 应用压缩包。
- Windows x64：`-setup.exe` 安装器与 `.app.zip` 应用压缩包。

打开 DMG 后，将左侧 WorkTodo 应用拖至右侧“应用程序”文件夹，再从“应用程序”启动。Windows 压缩包解压后运行 `WorkTodo.exe`，需已安装 WebView2 Runtime。

双平台构建工作流从同一提交生成安装包，并核对版本、源码提交、应用签名状态与文件哈希。构建报告、哈希和日志仅用于内部校验，更新说明填写在 Release 正文中。“关于”页面也可离线查看当前版本的更新日志。

macOS 原生图标使用黑底白色 Logo；应用内 Logo 随明暗主题切换并保持透明背景，托盘采用透明背景的实心白色标识。更改图标后需重新构建应用。

签名私钥与证书不纳入版本管理。正式签名材料由构建环境提供；未配置发行证书的构建会如实记录其签名状态。
